# Contributing

Start with [current state](docs/project/CURRENT-STATE.md) and [developer setup](docs/developers/README.md). Discuss scope before introducing plugins, large asset packs, or major systems.

Keep changes focused. Describe behavior, status, engine/toolchain, verification, and limitations. Separate proposals from working features. Update the roadmap and handoff when evidence changes. Include asset origins and redistribution rights. Never include credentials, saves, engine binaries, or unlicensed assets.

No open-source license is selected. Clarify licensing with the owner before substantial external contributions.
