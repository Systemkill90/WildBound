## Inside the creative workshop

The following are **draft concepts**, deliberately staged separately from the game's working prototype and accepted lore.

- [**Four original environment, village and creature vector studies**](https://github.com/Systemkill90/WildBound/blob/planning/truck-stop-2026-10-21/docs/art/concepts/README.md) — witchy Greenveil, Lanthfen marsh, fantastic fauna and different settlement styles.
- [**Expanded Idea Board**](https://github.com/Systemkill90/WildBound/pull/6) — strange animal anatomy, giant mushrooms, original village cultures and ancient speaking trees.
- [**Original fantasy villages draft**](https://github.com/Systemkill90/WildBound/pull/1) — ideas preserved for review, not treated as implemented NPCs.

## From study to game asset

A pretty image does not become a usable game asset automatically. Before production, each model or material needs a clear source, approved usage rights, correct scale, Unreal import settings and (when applicable) collision, animation, LODs and server performance testing.
