# Blightborn — approved creature concept references

**Owner approval:** October 23, 2026. The owner approved the nine visually distinct **Blightborn** creature designs shown together in a cinematic fantasy-horror bestiary concept board. The Blightborn are **original lifeforms born from chemically poisoned Sylweave**, not existing animals, and not Threnvahl (which are transformed humanoids from the human, elf and fae peoples only).

## Approved visual concepts

| Creature | Visual identity |
|---|---|
| **Glasshorn** | Tall, spectral, many-legged stalker with refractive jagged crystal antlers |
| **Rootmaw** | Low huge-jawed ambush predator formed from twisted roots, bone and chemical flesh |
| **Mirelung** | Bloated, floating, jellyfishlike swamp horror trailing luminous tendrils |
| **Thornback Howler** | Spined, predatory quadruped with a disturbing split-mouth silhouette |
| **Bloomwretch** | Unnerving upright flower-bearing entity with elongated limbs |
| **Carrion Spireling** | Skittering chitinous scavenger with long many-jointed limbs |
| **Bramblecoloss** | Massive low-slung bramble, root and crystal behemoth |
| **Veilstalker** | Tall, ghostly, hanging-root hunter in forest shadow |
| **Nightbloom** | Nocturnal winged creature with shredded translucent wings and vine anatomy |

**Approved shared style:** grotesque and darkly ethereal; a chemically altered union of flesh, bark, roots, crystal, fungus and eerie green luminescence. Preserve diverse silhouettes. Image names and appearances are accepted as concept references. The descriptive powers and ecology in the generated poster are not implemented or gameplay tested.
