# Prototype asset sources

Wildbound keeps art provenance alongside the content. Imported Unreal assets
are checked in with Git LFS; the original license applies to the source asset.

| Asset set | Source | License | Use in Wildbound |
| :-- | :-- | :-- | :-- |
| Greenveil forest ground, tree, fern, shrub, mossy rocks, stump, wooden bowl and bucket | [Poly Haven](https://polyhaven.com/) | [CC0](https://polyhaven.com/license) | Greenveil test-map environment and care-point dressing |
| Standing deer | [Innerscene — Deer standing](https://www.innerscene.com/tools/library/3d-parts/deer-standing-35e2f5f6) | CC0, public domain dedication | First deer visual; the prototype supplies server-controlled wandering and care stats |
| Electric Dreams Environment (local import) | [Epic Games / Fab](https://www.fab.com/listings/d79688f5-29be-4fb2-a650-2d4a813f5306) | Fab Standard License; use in a UE product is permitted, but source assets must not be redistributed as standalone files | Candidate foundation for the small Greenveil test map. Imported source remains local and is not committed to GitHub. |

Poly Haven says its models, textures and HDRIs are CC0 and may be used in
commercial work. Innerscene identifies the standing deer model as an original
CC0 asset. These assets are prototype art and do not imply Wildbound's final
art direction or animal animation quality.

Electric Dreams was selected after review of the rough first test map. Its Fab
source assets must not be redistributed through the public repository. New
New Unreal content is Git-ignored until reviewed; the local sample import is kept outside GitHub.
