# The Systems Behind the Wilderness

[← Field Guide](../README.md) · [World atlas](../world/README.md) · [Current state](../project/CURRENT-STATE.md)

*Good systems are the ones players can feel in the world around them.*

Wildbound's gameplay pillars are designed to support one another. A barn is useful because animals need shelter. A fence matters because wildlife moves. A shared home has meaning because players care for it together.

| System | The experience | Present reality |
| :-- | :-- | :-- |
| **[Animals & husbandry →](animals.md)** | Observe, earn trust, provide care and eventually raise distinctive lineages. | Standalone animal-needs rules tested; UE interactions unverified. |
| **[Building & homesteads →](building.md)** | Build cottages, barns, fences and bridges with expressive voxel materials. | Temporary snapped construction blocks compiled; no voxel engine. |
| **[Cooperative worlds →](multiplayer.md)** | Share a lasting world with friends, backed by server authority and recovery. | Two-client listen-server *connection* smoke test only. |
| **[World & habitats →](../world/biomes.md)** | Explore places with convincing ecology, atmosphere and mysterious magic. | Small Greenveil test clearing; other regions planned. |

## The first complete loop we want to prove

**Explore → approach an animal → provide care → build a safe enclosure → return together.**

Every stage must be observable in the editor or a launched package, with authoritative results across clients before we expand it.

[First-playable acceptance checklist](../developers/FIRST-PLAYABLE.md) · [Roadmap](../../ROADMAP.md)

## Future systems belong on the idea board

Breeding/genetics, full animal society, NPC villages, complex weather, mythical body plans and long-term farming are part of the game's vision, but their depth and implementation order have not all been approved.
