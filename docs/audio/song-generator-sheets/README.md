# Wildbound — Aquatic Song Generator Sheets

**Status:** Draft original songs and sound-direction concepts; preserved for future free/paid vocal music experiments. No final audio recordings or in-game singing implemented.

## Three songs

| Song | Culture | Generator-ready file | Musical direction |
| :-- | :-- | :-- | :-- |
| **Low the Lantern** | Brinefolk | [Text + full lyrics](01-low-the-lantern.txt) | 52 BPM, warm but mournful work shanty, low call-and-response ensemble |
| **Stone Below the Water** | Tidemarked / merfolk | [Text + full lyrics](02-stone-below-the-water.txt) | 46 BPM, layered underwater memorial hymn |
| **The Third Bell** | Luresingers / sirens | [Text + full lyrics](03-the-third-bell.txt) | ~38 BPM, deeply feminine contralto harmonies + angelic, eerie male countertenor duet |

Each text file includes an original style prompt for a music generator, **all song lyrics** with verse/chorus labels and practical production notes. Copy the STYLE PROMPT into a generator's style field and the LYRICS section into its lyrics field; generators vary in support for voice part labels, custom lyrics and duration.

## Audio files and rights

- Existing procedural mood studies, if present in the conversation, are **not completed sung performances** of these songs. Their public repository distribution was not authorized.
- No generated vocal tracks have been produced via Runway because the connected workspace plan did not allow music generation.
- Don't add final recordings to the public game repo until you verify the service/performer license permits commercial soundtrack distribution and preserve the origin/license record.
- The lyrics and style directions are original project concept drafts, not release commitments; keep proposals and approvals separate.

## Future recording checklist

1. Generate several candidate sung versions, preserving the exact words and the emotional identities above.
2. Save generator name, account/plan entitlement, generation date, relevant license/terms, source prompt and track IDs alongside chosen files.
3. Check audible lyrics and correct performer roles; avoid unintelligible vocals as the only source of gameplay clues.
4. Review and approve a composition before describing it as production soundtrack.
